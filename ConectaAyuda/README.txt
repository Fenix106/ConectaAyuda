# Conecta Ayuda

Página web inicial para la Casa de Reposo Mis Tatas.

## Cómo abrir el proyecto
1. Descomprime `ConectaAyuda.zip`.
2. Abre la carpeta `ConectaAyuda` desde Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes instalar la extensión Live Server y elegir "Open with Live Server".

## Configurar WhatsApp
1. Abre `js/script.js`.
2. Busca `const NUMERO_WHATSAPP = "519XXXXXXXX";`.
3. Reemplaza el valor por el número real del asilo, con código de país y sin el signo +, espacios ni guiones.
   Ejemplo ficticio: `51987654321`.
4. Guarda los cambios y prueba los botones.

## Personalizar imágenes
- El logotipo está en `img/logo.png`.
- Para incorporar fotografías reales, agrégalas a `img/` y modifica las tarjetas de actividades en `index.html` y sus estilos en `css/estilos.css`.

## Nota
El chatbot incluido es básico: responde preguntas frecuentes mediante reglas de JavaScript. No es todavía un chatbot con inteligencia artificial ni está conectado a una base de datos.
